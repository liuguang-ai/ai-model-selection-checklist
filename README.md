## 一、先分清：你是哪一类用户

| 类型 | 典型需求 | 更适合 |
|---|---|---|
| 开发者 | 在自己的程序里调不同模型 | 统一接口 + Key 的 API 聚合 |
| 普通使用者 | 打开网页就聊天、出图、做视频 | 网页工作台型平台，用积分结算 |

两类需求不同，不要混着比较。

## 二、选平台的 5 项自查

- [ ] **模型齐不齐**：对话、图片、视频、音频四类有没有；新模型多久上线。
- [ ] **价格公开吗**：不注册能不能看到每个模型的起价和计费方式。
- [ ] **计费看得懂吗**：计费单位是否清晰（见下表）；不同单位不能直接比大小。
- [ ] **隐私**：对话内容是否仅自己可见；导出是否方便。
- [ ] **稳定性**：只能靠试——先小额，拿真实任务跑，看高峰期是否排队、失败是否退还额度。

## 三、计费单位速查表

| 类型 | 常见计费单位 | 影响费用的主要因素 |
|---|---|---|
| 对话 | 按 Token（通常每百万 Token） | 输入长度、输出长度、是否有缓存 |
| 图片 | 按张 | 分辨率、模型档位、参考图数量 |
| 视频 | 按秒 / 按次 / 按 Token | 时长、分辨率、是否带参考视频或音频 |
| 音频 | 按字符 / 按秒 | 文本长度或音频长度、语种、音色 |

## 四、一次任务到底花多少：估算方法

- **对话**：粗略按“1 个汉字约 1 到 2 个 Token”估。总 Token = 输入 + 输出，乘以每百万 Token 单价。长文档总结要注意，输入通常占大头。
- **图片**：张数 × 单价，再乘以重试次数。先用低档模型出草稿，满意后再用高档模型定稿。
- **视频**：时长 × 每秒单价。带参考视频时，计费时长可能大于输出时长，下单前读清规则。
- **音频**：转写按音频秒数；配音按文本字符数，提前数一下字数最直观。

> 技巧：把所有单位都换算成“做完一件事花多少”，再比较。

## 五、小额试用：3 个真实任务

不要拿“你好”测试。设计 3 个你真实会做的任务，比如：

1. 一段 2000 字的长文总结或改写（测对话）。
2. 一张带文字的商品主图或海报（测图片，检查文字是否出错）。
3. 一段 5 到 10 秒的视频，或一段 300 字的配音（测视频或音频）。

记录：耗时、失败次数、是否退还额度、结果能否直接用。

## 六、生成结果的核对清单

- 文字：核对事实、数字、日期、引用来源。
- 图片：检查文字、手部等细节、品牌元素是否被改动。
- 视频：检查动作衔接、镜头抖动、人物一致性。
- 音频：试听发音、停顿、多音字。
- 所有对外发布的 AI 生成内容，按平台规则做 AI 标识。
